# Cobranza Tres Provincias

Sistema web para gestión de afiliados, cobranza mensual, tickets, recibos, cobradores, caja y rendición.

## Producción

`https://cobranza-tres-provincias.vercel.app`

## Desarrollo

```bash
npm install
npm run dev
```

Verificación antes de publicar:

```bash
npm run build
npm test
```

## Repositorio y despliegue

La rama principal es `main`. Vercel está vinculado al repositorio y despliega producción desde esa rama.

Para continuar el proyecto desde otra computadora, consultar `docs/MIGRACION-PC.md`.
